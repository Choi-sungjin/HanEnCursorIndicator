# 주식 수익률 계산기

브라우저에서 바로 실행되는 단일 HTML 주식 수익률 계산기입니다.

## 실행 방법

`stock-calculator/index.html` 파일을 더블 클릭하거나 브라우저에 드래그하여 엽니다.

## 기능

- **종목 관리**: 종목명, 매수단가, 수량을 입력해 매수금액을 자동 계산
- **등락률 입력**: 종목별로 ±% 등락률을 직접 입력
- **시장 시뮬레이션**: 슬라이더로 -50% ~ +50% 등락률을 전 종목에 일괄 적용
- **실시간 계산**: 현재가(호가), 평가금액, 손익, 수익률 자동 갱신
- **전체 요약**: 총 매수금액, 총 평가금액, 총 손익, 평균 수익률
- **자동 저장**: 브라우저 `localStorage`에 자동 저장되어 다음 방문 시 복원
- **한국식 색상**: 상승=빨강, 하락=파랑

## 사용 예시

1. "+ 종목 추가"로 종목을 추가합니다.
2. 종목명/매수단가/수량을 입력합니다 (매수금액은 자동 계산).
3. 등락률(%)을 입력하거나, 상단 슬라이더에서 시장 시나리오를 일괄 적용합니다.
4. 우측의 평가금액·손익·수익률이 즉시 갱신됩니다.

데이터는 외부 서버로 전송되지 않으며 현재 브라우저에만 저장됩니다.
