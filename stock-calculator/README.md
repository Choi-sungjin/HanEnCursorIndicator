# 주식 거래 시뮬레이터

브라우저에서 바로 실행되는 단일 HTML 주식 거래 시뮬레이터입니다. 매수·매도를 시간순으로 입력해 평단가 변화, 물타기·추격매수, 실현/미실현 손익을 확인합니다.

## 실행 방법

`stock-calculator/index.html` 파일을 브라우저로 엽니다.

## 주요 기능

- **다중 거래**: 한 종목에 매수/매도를 시간순으로 여러 번 입력
- **평단가 자동 재계산**: 가중평균 방식으로 매수/매도 시점마다 평단가를 갱신
- **물타기/추격매수 표시**: 매수 직후 평단가 변동률을 +(추격) / -(물타기)로 표시
- **실현/미실현 손익 분리**: 매도 시 실현 손익을 계산하고, 남은 보유분은 현재가 기준 미실현 손익
- **현재가 시뮬레이션**: 현재가 입력 + 슬라이더(±50%)로 가상의 가격 변화 적용
- **가격 차트**: 평단가 추이 + 현재가(점선) + 매수(▲) / 매도(▼) 마커
- **빠른 시나리오 프리셋**: 물타기/추격매수 예시 자동 채우기
- **자동 저장**: `localStorage`에 저장되어 브라우저 재방문 시 복원

## 사용 예시

1. "+ 종목 추가"로 새 종목 추가, 종목명 입력
2. 거래 추가 폼에서 날짜시간, 매수/매도, 단가, 수량 입력 → "+ 거래 추가"
3. 매수를 가격을 점점 낮추며 추가 → 평단가가 낮아지는 **물타기**
4. 매수를 가격을 점점 올리며 추가 → 평단가가 높아지는 **추격매수**
5. 매도를 추가하면 실현 손익이 누적, 잔여 수량은 미실현 손익으로 분리
6. 현재가 슬라이더를 움직여 가격 변동 시나리오 시뮬레이션

## 계산 방식

- **평단가**: 매수마다 `(이전평단 × 이전수량 + 매수단가 × 매수수량) / (이전수량 + 매수수량)`
- **실현손익**: 매도마다 `(매도단가 - 평단가) × 매도수량` 누적
- **미실현손익**: `(현재가 - 평단가) × 잔여수량`
- **총 수익률**: `(실현손익 + 미실현손익) / 누적 매수금액 × 100`

데이터는 외부로 전송되지 않으며 브라우저 `localStorage`에만 저장됩니다.
